💰 Meu Caixa - Controle de Recebimentos 

Sistema desktop para controle de recebimentos e movimentações de caixa, desenvolvido em Python com interface gráfica.

O projeto foi criado para facilitar o registro e acompanhamento de valores recebidos, permitindo organizar as movimentações por forma de pagamento e consultar o histórico de operações.

✨ Funcionalidades

💵 Registro de recebimentos
💳 Controle por forma de pagamento:
PIX
Cartão
Dinheiro
📅 Registro por data
📋 Histórico de movimentações
✏️ Edição de lançamentos
🗑️ Exclusão de registros
📊 Consulta e organização dos recebimentos
💾 Armazenamento local dos dados
🖥️ Interface gráfica desktop


🛠️ Tecnologias utilizadas
Python
PySide6 — interface gráfica
SQLite — banco de dados local
