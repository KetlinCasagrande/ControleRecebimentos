💰 Meu Caixa - Controle de Recebimentos 

Sistema desktop para controle de recebimentos e movimentações de caixa, desenvolvido em Python com interface gráfica.

O projeto foi criado para facilitar o registro e acompanhamento de valores recebidos, permitindo organizar as movimentações por forma de pagamento e consultar o histórico de operações.

✨ Funcionalidades

💵 Registro de recebimentos

💳 Controle por forma de pagamento:
PIX,
Cartão e
Dinheiro

📅 Registro por data

📋 Histórico de movimentações

✏️ Edição de lançamentos

🗑️ Exclusão de registros

📊 Consulta e organização dos recebimentos

💾 Armazenamento local dos dados

🖥️ Interface gráfica desktop



🛠️ Tecnologias utilizadas
Python
PySide6 — interface gráfica
SQLite — banco de dados local


🎯 Objetivo do projeto

Este projeto foi desenvolvido como uma aplicação prática para resolver uma necessidade real de controle financeiro e organização de recebimentos, além de servir como parte do meu aprendizado em desenvolvimento de aplicações desktop com Python.

Durante o desenvolvimento, foram praticados conceitos como:

Programação orientada a objetos
Desenvolvimento de interfaces gráficas
Manipulação de banco de dados SQLite
CRUD (criação, consulta, edição e exclusão de dados)
Organização de dados
Validação de informações
Estruturação de uma aplicação desktop
